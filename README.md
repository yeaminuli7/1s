# মুক্তকাট (MuktoCut)

**ফ্রি, অফলাইন Android ভিডিও এডিটর — লঞ্চ-ক্র্যাশ ফিক্স সংস্করণ `0.1.1`**

CapCut-এর মতো সহজ টাইমলাইন এডিটিং থেকে অনুপ্রাণিত, কিন্তু এটি একটি স্বাধীন অ্যাপ।
CapCut/ByteDance-এর নাম, লোগো, পেইড অ্যাসেট বা প্রোপ্রাইটারি ইফেকট কপি করা হয়নি।
বিজ্ঞাপন নেই, সাবস্ক্রিপশন নেই, পেইড লক নেই, এক্সপোর্টে ওয়াটারমার্ক নেই।

> এই সংস্করণটি CapCut-এর **সব** ফিচারের ক্লোন নয়। আগে মূল এডিটিং কাজগুলো
> বাস্তবে ব্যবহারযোগ্য করা হয়েছে; টেক্সট/ট্রানজিশন/AI ফিচার পরের ধাপে যুক্ত করার
> পরিকল্পনা আছে।

## APK ডাউনলোড ও ইনস্টল

`releases/` ফোল্ডারে দুটি সাইন করা APK আছে:

| ফাইল | কাদের জন্য |
|---|---|
| `MuktoCut-0.1.1-arm64-v8a.apk` | **বেশিরভাগ আধুনিক Android ফোন। প্রথমে এটি চেষ্টা করুন।** |
| `MuktoCut-0.1.1-armeabi-v7a.apk` | পুরোনো 32-bit ARM ফোন; arm64 APK ইনস্টল না হলে এটি চেষ্টা করুন। |

> `0.1.0`-এ অ্যাপ খুললেই ক্র্যাশ করত। `0.1.1`-এ সেই লঞ্চ ক্র্যাশ ফিক্স করা হয়েছে;
> পুরোনো APK ব্যবহার করবেন না।

প্রয়োজন: **Android 8.0 (API 26) বা নতুন**।

ইনস্টল করার নিয়ম:

1. APK ফাইলটি ফোনে ডাউনলোড/কপি করুন।
2. ফাইল ম্যানেজার বা ব্রাউজার থেকে APK খুলুন।
3. Android “unknown sources / install unknown apps” অনুমতি চাইলে সেই অ্যাপের জন্য অনুমতি দিন।
4. ইনস্টল শেষে **মুক্তকাট** খুলুন।
5. প্রথমবার ভিডিও যোগ করার সময় ফাইল পিকার থেকে ভিডিও বেছে দিন।

এগুলো **development-key দিয়ে সাইন করা sideload APK**, Play Store রিলিজ নয়।
একই প্যাকেজের পরের বিল্ড আপডেট হিসেবে ইনস্টল করার জন্য রিপোর `signing/debug.keystore`
ব্যবহার করা হয়েছে। পাবলিক প্রোডাকশন রিলিজের আগে নিজের প্রাইভেট release key ব্যবহার করুন।

## এই সংস্করণে যা আছে

- একাধিক ভিডিও ইমপোর্ট (Android ফাইল পিকার / Storage Access Framework)
- মাল্টি-ক্লিপ টাইমলাইন, আসল ভিডিও থাম্বনেইল, স্ক্রাব ও জুম
- প্লেহেডে **স্প্লিট/কাটা**
- ক্লিপ **ট্রিম**: নির্বাচিত ক্লিপের দুই প্রান্ত টেনে, অথবা সেকেন্ড লিখে সঠিক ট্রিম ডায়ালগ
- ক্লিপ **ভলিউম** ০–২০০% (১০০%-এর বেশি বুস্ট এক্সপোর্টে প্রয়োগ হয়)
- ক্লিপ কপি, বামে/ডানে সরানো, মুছে ফেলা
- আনডু / রিডু
- লোকাল প্রজেক্ট অটোসেভ ও প্রজেক্টের নাম বদলানো
- প্রিভিউ প্লে/পজ
- **MP4 এক্সপোর্ট**: H.264 ভিডিও + AAC অডিও, 30 fps, অটো/720p/1080p
- এক্সপোর্ট প্রগ্রেস নোটিফিকেশন, ব্যাকগ্রাউন্ড সার্ভিস ও বাতিল করার অপশন
- এক্সপোর্টের পর ফাইল খোলা/শেয়ার করা
- বাংলা UI, ডার্ক থিম

## কীভাবে ব্যবহার করবেন

1. **ভিডিও যোগ করুন** → ফাইল পিকার থেকে এক বা একাধিক ভিডিও বেছে দিন।
2. টাইমলাইনে আঙুল দিয়ে টেনে প্লেহেড সরান; ক্লিপে চাপ দিয়ে ক্লিপ নির্বাচন করুন।
3. কাটার জায়গায় প্লেহেড রেখে **স্প্লিট** চাপুন।
4. **ট্রিম**-এ শুরু/শেষ সেকেন্ড লিখুন, অথবা নির্বাচিত ক্লিপের প্রান্ত টানুন।
5. **ভলিউম**, **কপি**, **বামে/ডানে**, **মুছুন** দিয়ে ক্লিপ সাজান।
6. ভুল হলে উপরের **আনডু** চাপুন।
7. **এক্সপোর্ট** → রেজোলিউশন বেছে **সেভ লোকেশন বেছে নিন** → ফাইল পিকারে জায়গা/নাম নিশ্চিত করুন।
8. এক্সপোর্ট শেষ হলে নোটিফিকেশন/ডায়ালগ থেকে ভিডিও খুলুন বা শেয়ার করুন।

## গুরুত্বপূর্ণ সীমাবদ্ধতা (সৎভাবে বলা)

- টেক্সট, স্টিকার, ট্রানজিশন, ফিল্টার, স্পিড র‍্যাম্প, AI ক্যাপশন, ব্যাকগ্রাউন্ড
  রিমুভাল ইত্যাদি **এখনো যুক্ত নয়**।
- প্রিভিউ ক্লিপ পরিবর্তনের সময় ধীর ফোনে ছোট একটি prepare gap হতে পারে। এক্সপোর্ট
  আলাদা FFmpeg pass-এ frame-accurate ভাবে কাটা/জোড়া লাগায়।
- এক্সপোর্ট software re-encode (libx264) করে; লম্বা/4K ভিডিওতে সময় লাগবে। ধীর ফোনে
  720p বেছে নেওয়া ভালো।
- ভিন্ন রেজোলিউশন/আসপেক্ট রেশিওর ক্লিপ জোড়া লাগালে প্রথম ক্লিপের ক্যানভাসে
  letterbox/pad করা হয়; জোর করে crop করা হয় না।
- ১০০%-এর বেশি ভলিউম প্রিভিউতে শোনা না গেলেও এক্সপোর্ট করা ফাইলে যুক্ত হবে।
- সোর্স ভিডিও ফাইলগুলো ফোনে অ্যাক্সেসযোগ্য থাকতে হবে। ফাইল মুছে গেলে বা অনুমতি
  চলে গেলে প্রজেক্টের সেই ক্লিপ export করা যাবে না; আবার ইমপোর্ট করুন।
- প্রজেক্ট ফোনের অ্যাপ-প্রাইভেট স্টোরেজে সেভ হয়; ক্লাউড সিঙ্ক নেই।
- এই sandbox-এ বাস্তব Android ফোন/হার্ডওয়্যার এমুলেটর নেই। **বিল্ড, JVM লজিক টেস্ট,
  Robolectric API 26 স্টার্টআপ টেস্ট, সাইনেচার, zip alignment ও native ELF alignment
  যাচাই করা হয়েছে**; বাস্তব ডিভাইসে ইনস্টল/প্লেব্যাক/এক্সপোর্টের রানটাইম টেস্ট
  করা যায়নি। ফোনে চালিয়ে কোনো সমস্যা হলে ডিভাইস মডেল, Android ভার্সন ও ত্রুটি জানান।

## সোর্স থেকে বিল্ড

সাধারণ Android Studio/Gradle পথও আছে, তবে এই sandbox-এর সীমিত নেটওয়ার্কের জন্য
একটি self-contained বিল্ড স্ক্রিপ্ট রাখা হয়েছে:

```bash
python3 scripts/build_apk.py
# শুধু arm64:
python3 scripts/build_apk.py --abis arm64-v8a
# টেস্ট বাদ দিয়ে:
python3 scripts/build_apk.py --skip-tests
```

স্ক্রিপ্টটি pinned dependency নামায়, Java কম্পাইল করে, JVM টেস্ট চালায়, D8 দিয়ে
dex বানায়, per-ABI APK প্যাকেজ করে, 16 KB zip alignment করে, development key দিয়ে
সাইন করে এবং `apksigner verify` চালায়।

ঐচ্ছিক Gradle বিল্ড (আগে dependency fetch করতে হবে):

```bash
python3 scripts/build_apk.py --deps-only
gradle :android:assembleDebug
```

মূল কোড: `android/src/main/java/com/yeaminul/muktocut/`
লজিক টেস্ট: `android/src/test/java/com/yeaminul/muktocut/`

## যাচাই করা হয়েছে

- `EditProjectTest` ও `ExportPlannerTest` JVM-এ পাস
- Robolectric API 26-এ `MainActivity` create/start/resume/visible + measure/layout পাস
  (`0.1.0`-এর `TextureView.setBackgroundColor` লঞ্চ ক্র্যাশ রিগ্রেশন কভার করে)
- APK Signature Scheme v2/v3 ভেরিফাই
- `zipalign -c -P 16 4` পাস
- arm64-v8a APK-এর প্রতিটি shipped `.so`-এর ELF LOAD alignment `0x4000` (16 KB)
- `aapt dump badging`: minSdk 26, targetSdk 35, native-code ABI সঠিক
